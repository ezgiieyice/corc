# CORC

**Watch. Understand. Learn.**

CORC is an AI-powered language learning video player that generates transcripts and contextual Turkish translations from video content.

## v0.1

The first working version of CORC includes:

- Video playback
- Word-level transcript highlighting
- Turkish translations
- Clickable transcript navigation
- Playback speed controls
- Context-aware AI translation
- Translation quality-control pass
